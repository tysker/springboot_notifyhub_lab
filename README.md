## Notifyhub App

Modules

```
notifyhub/ (parent: dependency management only)
├── notifyhub-api plain Java: interfaces, DTOs, custom annotations
├── notifyhub-core Spring beans: channel implementations, config classes
└── notifyhub-app Spring Boot main class, REST controller, application.yml
└── notifyhub-search Spring Boot main class, OpenSearch integration, application.yml
``` 

Technologies

- Spring Boot
- OpenSearch
- PostgreSQL
- Java
