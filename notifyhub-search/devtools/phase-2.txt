# Check OpenSearch cluster health
GET _cluster/health

# Update all documents in the `notifications` index where the `channel` is `PUSH` to change the `channel` to `SLACK` and set the `recipient` to `#general`.
POST notifications/_update_by_query
{
  "query": {
    "term": { "channel": "PUSH" }
  },
  "script": {
    "source": "ctx._source.channel = 'SLACK'; ctx._source.recipient = '#general'"
  }
}

# Status 200 means the index exists and is healthy. Status 404 means the index does not exist.
HEAD notifications-v2
